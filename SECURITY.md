
# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Preflight, please report it privately using GitHub's **Report a vulnerability** feature under the repository's **Security** tab.

Please do not open a public GitHub issue to report security vulnerabilities. Public reports may expose sensitive information and put users at risk.

Private reporting allows the maintainers to investigate and address the issue before any details are disclosed publicly.

## What to Include in Your Report

When reporting a vulnerability, please include:

- A clear description of the potential security issue.
- Steps to reproduce the problem.
- The affected version of Preflight.
- The potential impact of the vulnerability.
- Any relevant logs or screenshots, with sensitive information removed.

## Privacy and Security

Preflight runs locally and never sends your project code anywhere. It does not print secret values in its findings or reports.

If you discover a case where a secret value is exposed in Preflight output, please report it privately. Reports about potential secret leakage are especially welcome.

**Never include live API keys, passwords, tokens, or other credentials in a public issue or report.**
